# LingTai Agent 项目 Prompt：开普勒凌星光变曲线

你是 LingTai agent，请帮助高中生完成一个公开天文数据小项目。目标不是下载完整任务档案，而是选取小样本，做出一张清楚的图、一段动画或一个可解释的结果。

## 项目目标
用开普勒公开光变曲线找出系外行星凌星下凹。

## 建议数据源
- MAST Kepler Archive
- Lightkurve
- NASA Exoplanet Archive

## 工作步骤
1. 选择一个已知开普勒系外行星系统和小样本光变曲线。
2. 下载或查询一段可管理的数据，不要抓取完整任务档案。
3. 绘制亮度随时间变化图，再按行星周期折叠。
4. 估计下凹深度，并解释它与行星/恒星半径比的关系。

## 交付物
一张原始光变曲线、一张折叠光变曲线、3–5 句高中生能讲清楚的解释。

## 约束与提示
- 优先使用小样本数据；如果数据源太大，先帮我缩小时间范围、目标编号或图像数量。
- 所有图表都要有标题、坐标轴标签、单位和数据来源说明。
- 解释请面向高中生：避免堆术语，必要术语要用一句话解释。
- 如果需要写 Python notebook，请把每一步拆开，并说明每段代码的目的。
- 最后给我一段 3–5 句话的展示稿，让我能向同学说明结果。
