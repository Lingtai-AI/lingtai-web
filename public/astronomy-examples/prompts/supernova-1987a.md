# LingTai Agent 项目 Prompt：超新星 1987A 光变曲线

你是 LingTai agent，请帮助高中生完成一个公开天文数据小项目。目标不是下载完整任务档案，而是选取小样本，做出一张清楚的图、一段动画或一个可解释的结果。

## 项目目标
用公开观测数据绘制超新星亮度随时间变化。

## 建议数据源
- AAVSO International Database
- AAVSO photometry search

## 工作步骤
1. 在 AAVSO 中查询 SN 1987A 的一小段光度数据。
2. 选择一个滤镜或清楚标注混合数据的限制。
3. 绘制亮度随时间变化，并找出峰值附近。
4. 解释快速变亮和长期变暗代表什么。

## 交付物
一张光变曲线、峰值/衰减标注、简短解释。

## 约束与提示
- 优先使用小样本数据；如果数据源太大，先帮我缩小时间范围、目标编号或图像数量。
- 所有图表都要有标题、坐标轴标签、单位和数据来源说明。
- 解释请面向高中生：避免堆术语，必要术语要用一句话解释。
- 如果需要写 Python notebook，请把每一步拆开，并说明每段代码的目的。
- 最后给我一段 3–5 句话的展示稿，让我能向同学说明结果。
