# LingTai skills

This permanent root is a small domain router. It owns no installation, migration,
repair, release, or other procedure.

- **Help** — [help/skill.md](https://lingtai.ai/help/skill.md): installation,
  migration, and future operational guidance.

a stop condition; this file never substitutes prose for an executable contract.
